# Drodis v2.0
Drawing game for family and friends. One device, everyone plays.

*Runs on latest browsers (Chrome, Firefox, Safari, Edge)

## Stack

- **Vite** + **React** + **TypeScript**
- **Tailwind CSS** 
- **shadcn/ui** 

## Dev

```bash
npm run dev      # dev server: http://localhost:5173
npm run build    # type-check + production bundle
npm run preview  # preview production build locally
```
